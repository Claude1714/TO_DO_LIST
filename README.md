# TO_DO_LIST

**Checkmark** is a to-do list that runs in any browser. It's a single HTML file with no install, no account and no server.

## Use it

Open `index.html` in a browser.

## Features

- Add tasks with an optional due date and High priority
- Tick tasks off, edit them with a double-click, or delete them
- Filter by All, Active or Done, and clear completed tasks
- Overdue tasks are marked in red
- A progress bar shows how many tasks are done
- Follows the device's light or dark mode

Tasks are saved in the browser's `localStorage`, so they stay on the device and browser that created them.
